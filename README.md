# Modern Music Player & Real-time Synced Lyrics

A sleek, pixel-perfect web music player inspired by Spotify / Apple Music, featuring:
- Dynamic adaptive background luminance
- Cascading staggered lyrics animation with scale effect & real-time sync
- Global music search (100M+ songs via iTunes) with automatic Full Audio extraction (`yt-dlp` + `ffmpeg`)
- Synced LRC lyrics integration via LRCLIB
- Automatic Vietnamese typography adaptation (`Be Vietnam Pro`)
- Frosted glass UI (backdrop blur) with dark aesthetic
